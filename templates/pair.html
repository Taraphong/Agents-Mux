จับคู่อุปกรณ์ (Pairing)

เว็บนี้ต้องจับคู่อุปกรณ์ก่อนใช้งาน สร้าง Pairing Key จากฝั่ง server แล้วนำคีย์มาใส่ที่นี่ คีย์แต่ละใบใช้ได้ครั้งเดียวและมีอายุ {{ ttl_minutes }} นาที

สร้างคีย์บนเครื่องที่รัน server:
python app.py --pairing-key · ./start_web.sh --pair
หลังจับคู่แล้วอุปกรณ์นี้จะเข้าใช้งานได้ {{ session_days }} วัน หรือจนกว่าจะถูกยกเลิกในหน้า Settings
